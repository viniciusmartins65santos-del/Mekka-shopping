SOBRE ESTE PROJETO

Privacidade e demonstração

O Mekka Shopping é um projeto acadêmico de desenvolvimento web da PUC-Campinas.

Uma experiência de demonstração

As ofertas e os preços servem para apresentar o funcionamento de um marketplace. Não são propostas comerciais. Não realizamos pagamentos, vendas ou contatos com vendedores.

As marcas e imagens são usadas como referências visuais no trabalho acadêmico. Os links dos fabricantes abrem sites externos.

Dados neste navegador

O cadastro guarda somente nome e e-mail fictícios durante a sessão da aba. As senhas, a data de nascimento e o gênero não são armazenados. O botão Sair encerra o acesso demonstrativo.

Os anúncios criados, incluindo sua imagem, ficam no armazenamento local deste navegador até você apagá-los. Eles não são publicados para outros usuários. As mensagens de contato e os pedidos de recuperação não são enviados nem salvos.

Use dados fictícios ao testar. Não há servidor de contas ou banco de dados neste projeto.

Apagar os dados da demonstração

Você pode remover os anúncios locais e o cadastro desta aba. O catálogo original continua disponível.
